# eda-code

Exploratory Data Analysis (EDA) \
\
This directory contains the scripts and Quarto documents used to explore, visualize, and summarize the cleaned *Salmonella* dataset. The goal of this phase was to identify patterns in AMR genotypes and assess the distribution of metadata features before moving into the predictive modeling stage.\
\
📂 Contents
01_eda.qmd: The primary Quarto document performing the analysis. It includes:\
\
- Data structure summaries.\
\
- Distribution plots for key variables (e.g., Year, Source, AMR).\
\
- Correlation checks between metadata features and AMR phenotypes.\
\
- Analysis Outputs: Figures and tables generated by these scripts are automatically saved to `results` sub-folder for use in the final manuscript.
